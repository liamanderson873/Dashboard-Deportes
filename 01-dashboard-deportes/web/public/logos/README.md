# Escudos de equipos

Recursos de identificación de los equipos, conservados sin recolorear ni deformar. Las marcas pertenecen a sus titulares; su presencia no implica afiliación ni aprobación.

- NBA: 30 logos del CDN oficial `cdn.nba.com`, ruta `/logos/nba/{id}/primary/L/logo.svg`.
- Fútbol: 121 escudos de las URLs de `crests.football-data.org` facilitadas por la base local.
- Inventario, URL original y SHA-256: `../../src/lib/team-logos.json`.
- Descarga comprobada el 13 de noviembre de 2026. Los SVG se han comprobado para rechazar scripts y contenido activo.

La interfaz usa estos archivos locales con dimensiones reservadas y una abreviatura alternativa si una imagen no puede cargarse. Los colores originales de las marcas se mantienen sobre una base neutra.
